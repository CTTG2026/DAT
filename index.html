Tổ này chưa có học viên nào.

Thêm khóa học mới

Chọn file XML "Đăng ký khóa học" (do Sở GTVT cấp) để tạo khóa học và danh sách học viên.

Thêm tổ mới

Tổ dùng để nhóm học viên theo giáo viên phụ trách, gán thủ công cho từng học viên.

Cập nhật ảnh chân dung

Chọn nhiều file JPG cùng lúc — mỗi file phải đặt tên đúng mã học viên, ví dụ: 82004-20260905-000016.jpg. Hệ thống tự khớp theo tên file.

Nhập file chia tổ (Excel)

File Excel cần có các cột: Khoá tổng, Tên tổ, Khóa học, Họ tên học viên, Mã học viên. Hệ thống tự tạo Tổ chưa có và gán từng học viên theo Mã học viên.
